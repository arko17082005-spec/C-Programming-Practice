# C Programming Practice & Solutions

Welcome to my C programming repository! This space contains structured code, algorithms, and data structures categorized by skill levels.

---

## 📂 Repository Structure

- **`Level 1 — Intermediate C`**: Basic constructs, arrays, numbers, and string manipulation.
- **`Level 2 — Strong Intermediate C`**: Functions, recursion, and pointers.
- **`Level 3 — Advanced High Level`**: Advanced C topics including structures and memory management.
- **`Data Structures in C`**: Implementations of fundamental data structures in C.

---

## 🛠️ Concepts & Topics Covered
- **Arrays & Searching/Sorting** (Kadane's algorithm, binary search, element rotations)
- **Strings** (Anagrams, palindrome, longest unique substrings)
- **Functions & Pointers** (Dynamic memory allocation, double pointers, function pointers)
- **Structures & Applications** (Management system projects)
- **Data Structures** (Linked Lists, Stacks, Queues, Trees)

- **Language**: C (C99 / C11)
